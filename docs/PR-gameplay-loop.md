# 补齐地图版阶段目标、粮食恢复和安全转生闭环

玩家原先主要依靠下一项科技提示，研究完成后的建设与岗位配套、高级系统入口以及转生后的下一轮缺少承接。本次从真实游戏状态生成可操作阶段目标，补充当前粮食风险与恢复入口，并把高级系统和新周目接入同一份进度。

转生与挑战开启在原版破坏性钩子执行前备份。重置结果使用提交标识落盘，失败和响应丢失时复用同一候选结果，避免重复重置并保持多窗口版本保护。旧档不要求新增字段，回归摘要不会再次结算离线进度。

实现范围和场景规格见 `openspec/changes/complete-gameplay-loop/`；验证矩阵和浏览器验收缺口见 `docs/游戏进程闭环验证.md`。自动检查包括本地 HTTP/磁盘测试、原版引擎回归与 OpenSpec 严格校验；提交后的结果另附检查记录。浏览器端到端验收尚待完成，因此该变更暂不归档。
