# 游戏进程闭环：开发与验证记录

变更：`openspec/changes/complete-gameplay-loop`。基线：`feature-v1@5fd9d4b`。本记录区分自动验证与浏览器验收。

## 已实现

阶段引导覆盖采集、田地、住房、人口、学者、矿井与矿工、工坊、冶炼厂、工厂与工程师。目标按实际存档推导；科技完成后接续生产配套。支持收起/重开引导、科技追踪和高级方向追踪。

阻塞区分解锁、资源容量、地块槽位、库存、合成原料与原版额外条件。配方链检测循环，不修改经济状态。粮食卡使用实际游戏速度估计当前速率下的耗尽时间，暂停时不倒计时，解除风险后提示恢复。零人口可继续经营。

贸易、宗教、太空、政策、工程师生产、时间和挑战按照真实页签可见性提供入口。地图与原版共用实例，返回地图后重新评估目标。未开放时说明前置条件。

转生保留原版确认和挑战钩子，先保存备份再执行一次重置。服务端用 `operationId` 识别相同结果，响应丢失时客户端回读，失败重试复用同一结果，版本冲突保持暂停。普通转生与挑战开启都走此保护。新周目展示实际结算摘要，可确认已读。

`progression.version=1` 是可选展示元数据，旧档缺失或未知版本均从真实经济状态重新推导。回归摘要只比较上次保存的基线，不再次结算离线收益。

## 运行说明

升级后需重启本地服务，新的转生入口会核验 `resetProtocol=1`。旧服务不会静默执行缺少幂等保护的新转生流程。提交失败后不要重复点击转生，可在存档管理中“重试转生结果保存”或恢复转生前备份；冲突时先载入最新磁盘进度。
