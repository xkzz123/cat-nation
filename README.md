# 猫国建设者 · 本地版

这是 Kittens Game 原版源码的个人离线运行版本，保留原版玩法、中文翻译和作者链接。

## 六边形像素地图版

现在双击 **start.cmd** 默认进入地图主界面。旧存档首次打开会自动生成地区布局，继续使用原来的资源、建筑、科技和经济规则。

- 点击地区建设，管理职业、科技和工坊；顶部目标提示下一项科技及资源、容量缺口。
- 点击右上角或管理栏的「科技树」，打开国策树式科技链路图：完整节点、前置连线、搜索、平移缩放、实时费用、效果和开放内容，可直接研究或追踪目标。
- 地图支持拖动平移、滚轮缩放、俯仰 30°～90°与左右旋转；视角、领地、地区和目标随进度一起保存。
- 右上角「游戏速度」可选 ×1、×2、×3、×5、×10、×20，刷新后保留选择；暂停停止推进，自动存档仍按现实时间计时。
- 同类地区可规划多格，每格默认 10 个建筑槽位，独立建造、逐个拆除；新地块从零开始，拆除按记录的建造成本返还 50%。
- 高级宗教、贸易、太空、政策和挑战通过右上角「原版界面」管理，点击「返回地图」继续。两者共用同一个游戏实例。
- [地块容量与拆除配置](docs/地块容量与拆除配置.md)：修改每格容量、拆除返还比例，以及旧存档迁移规则。
- [地图版使用与实现说明](docs/地图版使用与实现说明.md)：开局流程、地区规划、科技引导、存档迁移和代码入口。
- [地图构建方案与进度](docs/六边形像素地图构建方案.md)：保留原设计讨论，并标注本次落实范围。

- 双击 **start-map-demo.cmd** 打开独立小 Demo，可选格、切换四季、调节俯仰和左右旋转、在空草地试放建筑；刷新还原，不改动原版存档。
- [Demo 页面](game/hex-demo/index.html)。原版服务运行时也可访问 `http://127.0.0.1:8765/hex-demo/index.html`。

## 开始游戏

1. 双击本目录的 **start.cmd**，会自动打开浏览器。
2. 保持启动窗口运行。游戏地址默认为 **http://127.0.0.1:8765/**。
3. 玩完先点击顶部「保存并备份」，成功后可以关闭页面和启动窗口。

只需本机 Node.js 20 或更新版本，本机已安装；不需要 npm install，不需要账号，也不需要联网。也可以在本目录运行 `npm start`，然后打开上述地址。

macOS 和 Linux 可运行 `npm run launch`，自动启动服务并打开默认浏览器；Windows 仍可双击 `start.cmd`。浏览器启动失败时会打印访问地址，服务继续运行，可手动打开。

默认端口被占用时，可通过 `CAT_NATION_PORT` 设置 1–65535 的端口，`npm start` 和 `npm run launch` 都会使用它。例如 macOS/Linux：

```bash
CAT_NATION_PORT=8766 npm run launch
```

Windows 命令提示符：

```bat
set CAT_NATION_PORT=8766
node launcher.mjs
```

更换端口会改变浏览器存储所属地址；磁盘存档仍使用原来的 `data` 目录。

### 监听地址和域名入口

- `CAT_NATION_HOST`：监听地址，默认 `127.0.0.1`；需要局域网直连时可显式设为 `0.0.0.0`。
- `CAT_NATION_PORT`：监听端口，默认 `8765`。
- `CAT_NATION_BASE_URL`：浏览器访问的 HTTP(S) 根地址，例如 `https://cats.example/`。不配时使用本地监听地址；不支持子路径部署。

反向代理与游戏在同一台机器时，保持回环监听即可，无需监听 `0.0.0.0`：

```bash
CAT_NATION_BASE_URL=https://cats.example/ npm run launch
```

DNS 和 HTTPS 由部署者配置，代理转发到本机游戏端口，并保留原始 Host。服务只接受本地地址及显式配置域名的 Host/Origin；不信任任意转发头。启动器始终通过本地地址探活，浏览器使用配置的域名入口。配置入口不会自动创建 DNS、证书或隧道。

本版本没有账号鉴权，所有访问者共用同一份磁盘存档；域名入口应置于有访问认证的反向代理之后，不应直接公开存档读写接口。

## 存档与备份

- 自动存档默认每 15 秒一次，可在地图顶部「自动存档」下拉框或「存档管理」中选择 5 秒、15 秒、30 秒、1 分钟、2 分钟、5 分钟、10 分钟。修改立即重新计时，并记住当前浏览器的选择；暂停游戏时仍按此间隔保存。手动保存、切到后台与退出页面仍会额外尝试保存。状态栏显示磁盘实际确认的保存时间，历史自动快照仍最多每分钟一份。
- **data/latest.json**：当前存档。启动时优先以它恢复；如果磁盘存档不存在，则尝试保留同一浏览器中的副本。两处都没有存档时创建新游戏。
- **data/backups/**：每分钟一个自动快照，保留最近 240 份；手动备份、导入与恢复前的备份长期保留，不会自动清理。
- 「存档管理」可以立即保存、下载 JSON、导入 JSON/原版压缩文本、选择历史备份恢复。导入和恢复前会先保留当前磁盘进度。
- 原版的「删档」会开启新游戏，但之前的磁盘进度仍会保留在 `before-new` 备份中。原版的「重置」仍是游戏内的转生机制，转生前会保留手动备份，转生结果写入磁盘后才刷新。
- 多窗口写入会校验存档版本；发现旧窗口覆盖风险时会拒绝写入并暂停旧窗口。请只用一个窗口玩。
- 突然关闭页面、终止进程或断电时，最后一次成功保存后的进度可能丢失；保存失败会在右下角显示原因。请勿在服务关闭后继续玩。

换浏览器或清理缓存后，继续使用同一项目、同一地址启动即可。搬到另一台电脑时复制整个项目（尤其是 **data**），或导出存档后在新电脑导入。**浏览器里的原官网存档不会自动迁移；已丢失且没有备份的进度不能凭空恢复。**

若 `latest.json` 损坏导致无法加载：先停止服务，将整个 `data` 文件夹复制留底，然后从 `data/backups` 选择一份 JSON，复制到 `data/latest.json`（不要移动原备份），再启动。备份文件与当前存档使用同一种封装格式。游戏内导出的纯 JSON 应通过导入按钮加载，不要直接用它覆盖 `latest.json`。

## 本地运行范围

游戏资源和依赖全部位于 `game/`，仅监听本机 127.0.0.1。移除了页面统计脚本，关闭了 KGNet 在线同步与价格请求，并通过页面策略限制后台网络请求。作者、Wiki、Steam 等外链仍保留，主动点击时会联网。地图顶部与原版右下角都可打开存档管理，无需登录；小窗口会将地图和管理面板上下排列。若地图加载异常，可直接访问 `http://127.0.0.1:8765/?view=classic` 使用原版界面。

## 检查

运行 `npm test`，检查硬盘存档、恢复与冲突保护、六角坐标、旋转选格和地区迁移。测试使用临时目录，不会改动你的 `data`。

开发时可执行 `npm install --prefix game --ignore-scripts --no-package-lock` 安装原项目测试依赖，再运行 `npm run test:game`。它包含原版回归测试，以及地图操作的真实扣费、科技前置、职业、合成和存档往返验证；正常玩游戏不需要安装这些依赖。
